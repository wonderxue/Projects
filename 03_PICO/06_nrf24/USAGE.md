# Pico nRF24L01+ 使用说明

## 修复的问题

你提到的非常重要：**nRF24L01+ 没有复位引脚**！我已经修正了代码。

## 正确的引脚配置

### nRF24L01+ 实际需要的引脚：
- **CS** (Chip Select) - 片选信号
- **CE** (Chip Enable) - 芯片使能
- **IRQ** (Interrupt Request) - 中断请求（可选，但推荐）
- **SPI** (MOSI, MISO, SCK) - SPI通信引脚

### 已移除的错误配置：
- ❌ **RST引脚** - nRF24L01+没有专门的复位引脚

## 硬件连接

```
Pico GPIO    ->  nRF24L01+
-----------------------------
3 (MOSI)     ->  MOSI
4 (MISO)     ->  MISO  
2 (SCK)      ->  SCK
26 (CS)      ->  CSN
15 (CE)      ->  CE
14 (IRQ)     ->  IRQ (可选)
```

## 可用的固件

### 1. 发送模式 (Transmitter)
- **文件**: `pico-nrf24_transmit.uf2`
- **功能**: 每秒发送 "Hello World! #0", "Hello World! #1", ...
- **用途**: 作为发送端，向接收端发送数据

### 2. 接收模式 (Receiver)  
- **文件**: `pico-nrf24_receive.uf2`
- **功能**: 监听并接收来自发送端的数据
- **用途**: 作为接收端，接收发送端的数据

### 3. 默认模式
- **文件**: `pico-nrf24.uf2` 
- **功能**: 与发送模式相同
- **用途**: 默认发送程序

## 使用方法

### 1. 选择模式
根据需要选择对应的.uf2文件：
- 发送数据：使用 `pico-nrf24_transmit.uf2`
- 接收数据：使用 `pico-nrf24_receive.uf2`

### 2. 烧录固件
1. 按住Pico板上的BOOTSEL按钮
2. 将Pico连接到电脑
3. 释放BOOTSEL按钮
4. 将对应的.uf2文件拖拽到RPI-RP2驱动器

### 3. 连接硬件
按照上面的引脚连接表连接nRF24L01+模块

### 4. 测试通信
- **发送端**: 通过串口监视器可以看到发送状态
- **接收端**: 通过串口监视器可以看到接收到的数据

## 通信地址

发送和接收使用相同的地址：
```cpp
uint8_t addr[] = {0x01, 0x23, 0x45, 0x67, 0x89};
```

## 串口监视器设置

- **波特率**: 115200
- **数据位**: 8
- **停止位**: 1
- **校验位**: 无

## 故障排除

1. **无法通信**: 检查引脚连接是否正确
2. **电源问题**: 确保使用3.3V供电
3. **距离问题**: nRF24L01+有效距离约10米
4. **频道干扰**: 确保周围没有2.4GHz干扰源
